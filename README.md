# Petteia 古希腊棋

8×8 夹吃棋：走子如车，被夹住的敌子出局。纯标准库，终端可玩。

## 规则（重构版，诚实声明）

Petteia 是古希腊文献中提到的棋类，具体规则已失传。本项目采用常见的
"custodian capture" 重构规则，并非考古定论：

- 8×8 棋盘，双方各 8 子：甲（●）占第 0 行，乙（○）占第 7 行。
- 每回合走一子，沿横/竖直线走任意格（车式走法），不能跳过棋子。
- **夹吃**：走子落定后，与其正交相邻的敌子、若另一侧紧贴己方棋子，
  则被吃掉（一次可多方向同时吃）。
- **不自杀**：主动把自己的子走到两敌子之间，不会被吃。
- 吃光对方全部棋子，或对方轮到时无合法走法，即获胜。
- 同一局面出现三次判和；300 半回合上限防无限对局，撞上限判和棋。

## 玩法

```bash
python3 -m petteia              # 人机对战（你是甲 ●）
python3 -m petteia --auto       # AI 对 AI 演示 1 局
python3 -m petteia --auto --games 10 --seed 42
```

人机模式输入如 `0,3 2,3`（起点 终点），`q` 退出。

## 已知局限

- 规则为重构版本，古希腊原始规则已不可考，本实现只是其中一种合理解读
- AI 只是 1 步贪心启发式（吃子 > 避重复局面 > 贴近敌子 > 威胁 > 机动性），
  不做深层搜索；熟悉规则的人类通常能赢
- 300 半回合上限是防无限对局的工程兜底，实战中很少撞到
- 文本回合制，无图形界面/存档/悔棋
- Python 3.10+，纯标准库
